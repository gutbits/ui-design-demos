Layout & Grids

Structure is the skeleton of every interface. Master Flexbox, CSS Grid, the 8-point system, and responsive breakpoints to build layouts that hold together at any size.

Flexbox — One-Dimensional Layout

Flexbox lays items out along a single axis (a row or a column) and excels at distributing space and aligning content. Toggle the properties below and watch the live container respond.

When to reach for Flexbox: navigation bars, button rows, centering a single element, toolbars, and any group of items that flows along one line. Use gap for spacing rather than margins on children.

CSS Grid — Two-Dimensional Layout

Grid controls rows and columns at once. Define tracks with grid-template-columns and let items span multiple cells. The fr unit divides leftover space into fractions.

Grid vs Flexbox: use Grid when you need alignment in two directions (a page scaffold, an image gallery, a dashboard). Use Flexbox for content that flows in one direction. They compose well — Grid for the page, Flexbox inside each cell.

The 8-Point Grid System

Restrict every size, margin, and padding to multiples of 8 (with 4 as an occasional half-step). This keeps spacing consistent, scales cleanly across screen densities, and removes hundreds of arbitrary decisions.

Why 8? Most screen sizes are divisible by 8, so layouts snap to whole pixels at 1x, 1.5x, 2x, and 3x densities. Google's Material Design and most major design systems are built on it.

Responsive Breakpoints

Breakpoints are the widths where your layout changes. Design mobile-first (smallest screen as the base) and add complexity upward with min-width media queries.
