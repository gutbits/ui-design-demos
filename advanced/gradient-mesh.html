Gradient Mesh

Complex, multi-point gradients with pure CSS — layered radial blobs, conic sweeps, blend modes, and the "blurred blob" technique that powers today's most lush backgrounds.

What Is a Mesh Gradient?

A linear or radial gradient blends between a handful of stops along one axis. A mesh gradient blends between many color points scattered across a 2D plane, producing soft, organic, multi-directional color fields — like the iOS lock screen or Stripe's marketing hero.

Native CSS has no single mesh-gradient() function, but you can fake one convincingly by stacking several radial-gradient() layers, each anchored at a different point with at x% y% and fading to transparent. The layers blend where they overlap.

5× layered radial-gradient
.mesh { background-color: #6c5ce7; /* fallback base */ background-image: radial-gradient(at 12% 18%, hsla(265,95%,68%,1) 0px, transparent 50%), radial-gradient(at 88% 12%, hsla(186,95%,60%,1) 0px, transparent 50%), radial-gradient(at 20% 85%, hsla(330,90%,62%,1) 0px, transparent 50%), radial-gradient(at 80% 78%, hsla(40,95%,60%,1) 0px, transparent 50%), radial-gradient(at 50% 50%, hsla(210,90%,60%,0.7) 0px, transparent 60%); }
Key trick: each blob fades to transparent at ~50%, so neighbouring blobs bleed into one another instead of forming hard edges. Keep stops at 0px → transparent 50–60% for the softest mesh.

Conic Gradients

Where radial gradients radiate outward, conic gradients sweep around a center — the basis for pie charts, loaders, and color wheels.

/* angle sweep around 50% 50% */ .ring { background: conic-gradient(from 220deg at 50% 50%, #6c5ce7, #00cec9, #fd79a8, #fdcb6e, #6c5ce7); } /* pie / progress: hard stops with repeated angles */ .pie { background: conic-gradient(#00cec9 0 65%, #2e3346 65% 100%); border-radius: 50%; }

Repeat the same angle for two adjacent stops (e.g. 65% 65%) to get a hard edge instead of a blend — that's how conic gradients draw crisp pie slices and donut charts without SVG.

Blend Modes

Blend modes control how stacked layers mix mathematically. They turn flat overlapping gradients into rich, lit-from-within color.

background-blend-mode mixes the multiple backgrounds of a single element; mix-blend-mode mixes an element with whatever sits behind it. The same blob set produces wildly different moods per mode:

  • screen / lighten — additive, glowing; great on dark bases.
  • multiply / darken — subtractive, like overlapping inks; great on light bases.
  • overlay / soft-light — contrast-boosting; adds depth without washing out.
  • color-dodge — intense highlights; use sparingly for neon hotspots.
.lights { background: radial-gradient(circle at 25% 30%, #ff006e, transparent 55%), radial-gradient(circle at 75% 35%, #3a86ff, transparent 55%), radial-gradient(circle at 50% 80%, #ffbe0b, transparent 55%); background-blend-mode: screen; background-color: #07070f; }

The "Blurred Blob" Technique

The most controllable mesh: position solid colored circles, blur them into soft clouds, and clip to the container. Easy to animate, easy to recolor, no gradient math.

.stage { position: relative; overflow: hidden; background: #0c0e16; } .blob { position: absolute; border-radius: 50%; filter: blur(60px); /* the magic: turns a circle into a soft cloud */ opacity: 0.85; } .blob.b1 { width:220px; height:220px; background:#6c5ce7; top:-40px; left:-30px; } .blob.b2 { width:260px; height:260px; background:#00cec9; bottom:-60px; right:-40px; }

Why designers love it:

  • Independent layers — animate each blob's position or hue separately for living backgrounds.
  • Cheap to recolor — change one background, not five gradient stops.
  • Naturally soft — Gaussian blur gives a smoother falloff than any gradient stop.
Performance: filter: blur() is GPU-heavy on large, animated elements. Keep blurred layers modestly sized, add will-change: transform when animating, and avoid blurring a full-viewport element on low-end mobile.
