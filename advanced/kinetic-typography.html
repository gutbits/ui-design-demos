Kinetic Typography & Animated Type

Text that moves, morphs, reveals and reacts. Variable-font animation, character-split reveals, scramble decode effects, marquees, glitch, aurora gradients and per-letter motion — built with vanilla CSS and JS.

variable-fonts clip-path background-clip:text requestAnimationFrame prefers-reduced-motion

What is kinetic typography?

Animating text to carry meaning, rhythm and emotion — not just decoration. Motion directs attention, sequences reading order, and adds personality, but it must stay subordinate to legibility.

The demos below are all real and self-contained: no GSAP, no Lottie, no framework. They lean on a small set of primitives — splitting text into spans, animating font-variation-settings, clipping gradients to glyphs with background-clip: text, slicing layers with clip-path, and driving frame-by-frame motion with requestAnimationFrame. Every effect freezes to a readable final state when the user prefers reduced motion.

1 · Per-character reveal

Split a headline into individual <span> characters in JS, then animate them in with a staggered transform and opacity. The original text stays as an aria-label for screen readers.

Design in motion
45ms
// split into chars, keep original text accessible el.setAttribute('aria-label', text); el.innerHTML = [...text].map(c => c === ' ' ? ' ' : `<span class="char" aria-hidden="true">${c}</span>` ).join(''); // stagger the .in class per index chars.forEach((ch, i) => setTimeout(() => ch.classList.add('in'), i * stagger));

2 · Text scramble / decode

The classic "decrypting" effect: each slot cycles through random glyphs, then locks onto its final character one position at a time. Pure timers and a frame loop.

ACCESS GRANTED
// each char resolves after a random start, scrambling until then const chars = '!<>-_\\/[]{}=+*^?#________'; function frame() { let out = '', done = 0; for (const q of queue) { if (frameCount >= q.end) { done++; out += q.to; } else if (frameCount >= q.start) { if (!q.char || Math.random() < 0.28) q.char = chars[Math.random() * chars.length | 0]; out += `<span class="dud">${q.char}</span>`; } else out += q.from; } el.innerHTML = out; if (done < queue.length) requestAnimationFrame(frame); }

3 · Variable-font weight animation

One font file, a continuous range of weights and widths. Animating font-variation-settings morphs the letterforms themselves — far smoother than swapping discrete weights. This uses Roboto Flex (wght 100–1000, wdth 25–151).

VARIABLE
auto
@keyframes pulse { 0%, 100% { font-variation-settings: "wght" 100, "wdth" 75; } 50% { font-variation-settings: "wght" 900, "wdth" 125; } } .word { animation: pulse 4s ease-in-out infinite; } /* hover variant — animate one axis on interaction */ .word:hover { font-variation-settings: "wght" 1000; }

4 · Gradient / aurora animated text

A multi-stop linear gradient is clipped to the glyphs with background-clip: text and the background-position is animated, so colour appears to flow through the letters.

aurora flow
.aurora { background: linear-gradient(110deg, #7aa2ff, #38e1c6, #ffb86c, #c792ea, #7aa2ff); background-size: 300% 100%; -webkit-background-clip: text; background-clip: text; color: transparent; animation: flow 6s linear infinite; } @keyframes flow { to { background-position: 300% 50%; } }

5 · Glitch text

Two pseudo-element copies of the text are offset in colour and sliced with clip-path: inset(), then jittered on hover. No images, no JS — the text content lives in data-text.

6 · Wavy / per-letter sine motion

Each letter is a span; a requestAnimationFrame loop offsets its translateY by a sine wave whose phase shifts per index, producing a travelling ripple. The speed slider scales the angular velocity.

Techniques

The building blocks behind every effect above, and where each one earns its keep.

Character / word splitting

Wrap each char, word or line in a span so you can stagger or transform them independently. Roll your own (as above) or use GSAP SplitText for line-aware splitting that survives wrapping. Always restore an accessible label.

Variable fonts

A single file exposes continuous axes (wght, wdth, slnt, opsz, plus custom axes). Animate them via font-variation-settings. See Google Fonts variable fonts.

clip-path

Slice and reveal type without masks or images. clip-path with inset(), polygon() or circle() powers wipes, glitch slices and reveal-on-scroll.

background-clip: text

Paint a gradient, image or animated background and clip it to the glyph shapes. Pair with an animated background-position for flowing colour, or a conic-gradient for a shimmer sweep.

SVG text

Use <text> with stroke-dasharray/stroke-dashoffset for handwriting effects, or <textPath> to run type along a curve. Crisp, scalable, and animatable with SMIL or CSS.

WebGL text

For displacement, fluid and particle type, render glyphs to a texture or use MSDF fonts and animate in a fragment shader (three.js, OGL, Curtains). Powerful but heavy — reserve it for hero moments. See web.dev for lighter-weight text layout tooling.

Principles

Motion should serve reading, never fight it.

Readability first

The reader must be able to parse the words at every frame, or at minimum at rest. If an effect makes text momentarily illegible, keep it brief and ensure a stable, readable end state.

Timing & easing

Use eased curves (cubic-bezier), short durations (150–600ms for reveals), and small staggers (30–60ms). Linear, slow or jittery motion reads as cheap or distracting.

Hierarchy

Animate one focal element per view. Reserve kinetic treatment for headlines, hero words and calls to action — competing animations flatten hierarchy and exhaust the reader.

Don't animate body copy

Long-form paragraphs should sit still. Continuous motion under reading text spikes cognitive load and harms comprehension. Save kinetic effects for display type.

Honest caveats

Kinetic type is easy to overdo. Mind these before shipping.

Accessibility. Splitting text into per-character spans destroys it for screen readers and copy/paste reliability.
  • Put the real string in aria-label on the container and mark the spans aria-hidden="true" (every JS demo here does this).
  • Always honour prefers-reduced-motion: reduce — freeze every effect to its final readable state, as the CSS in this page does.
  • Glitch and scramble effects can trip assistive tech and parsers; keep the accessible text static underneath.
Performance. Animate only transform and opacity where possible — they're compositor-friendly. Animating font-variation-settings, clip-path or background-position can trigger paint; profile on low-end devices and use will-change sparingly. A per-letter rAF loop on a long string is many style writes per frame — batch and cap them.
Legibility & motion sickness. Rapid, looping or parallax-style text motion can cause discomfort, nausea or vestibular distress for some users. Keep amplitudes small, avoid infinite high-frequency loops near body text, and never gate content behind an animation that can't be skipped.
