Accessibility Notes

Better than neumorphism — but mind the pastels

Claymorphism is far friendlier to accessibility than neumorphism because clay objects use their own fill color, distinct from the background, plus a real drop shadow. Boundaries are visible, so it can satisfy WCAG 1.4.11 Non-text Contrast (3:1) for component edges.

The real risk is text contrast: soft pastel fills make white or light text fail WCAG 1.4.3 (4.5:1). Always check label/background pairs — use a darker text tone on light clay, and reserve white text for sufficiently saturated fills. Don't let the inner highlight wash out small text, and keep a visible focus ring on interactive clay elements.

/* Keep clay accessible: distinct fill + checked text contrast */ .clay-btn { background: #7c5cff; /* saturated enough for white text (AA) */ color: #ffffff; } .clay-card { /* light fill -> dark text, never white */ background: #ffffff; color: #5b3fb0; } .clay-btn:focus-visible { outline: 3px solid #2d2356; outline-offset: 3px; }

History & Theory

Claymorphism emerged around 2021 as a warmer, more usable cousin of neumorphism. The term was popularized by designer Michal Malewicz (who also helped name neumorphism), describing a style of "inflated", clay-like 3D objects with rounded everything and a candy-soft palette.

It rode the same wave as the friendly 3D illustration trend seen in big-tech rebrands and product art around 2020–2022 — think the puffy, rounded icons in the era's marketing pages and emoji-like graphics. Claymorphism brings that bubbly aesthetic into actual UI components.

The three-shadow formula:

  • One large outer drop shadow — soft and offset downward, so the object clearly floats above the page
  • One inner bottom shadow — a darker tint of the fill, giving the underside curvature
  • One inner top highlight — a bright white inset, suggesting a glossy, rounded top edge catching light
  • Generous border-radius — often 30–50px, sometimes asymmetric, for that pinched-clay silhouette
  • Pastel, candy-like colors — soft pinks, mints, lilacs and butter yellows

Why it works better than neumorphism: Because each clay object has its own color and a real drop shadow, affordances are obvious — you can tell what's a button. It keeps the soft, tactile charm without the contrast catastrophe.

When to use: Playful, consumer-facing products — kids' apps, education, wellness, fintech onboarding, landing pages, illustration-led marketing — where a friendly, approachable personality is the goal. When to avoid: dense data tools, enterprise dashboards, or any serious/utilitarian context where the bubbly look reads as unprofessional. As always, verify text contrast on those tempting pastel fills.
