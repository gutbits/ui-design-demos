// Ripple effect — JavaScript implementation function createRipple(event) { const btn = event.currentTarget; const circle = document.createElement('span'); const diameter = Math.max(btn.clientWidth, btn.clientHeight); const radius = diameter / 2; circle.style.width = circle.style.height = diameter + 'px'; circle.style.left = (event.clientX - btn.getBoundingClientRect().left - radius) + 'px'; circle.style.top = (event.clientY - btn.getBoundingClientRect().top - radius) + 'px'; circle.classList.add('ripple'); btn.appendChild(circle); setTimeout(() => circle.remove(), 600); }

History & Theory

Material Design was introduced by Google at I/O 2014, created by Matías Duarte. It was Google's answer to the question: "What lies between skeuomorphism and flat design?"

The core metaphor is "material" — a magical paper that can split, join, resize, and cast shadows. Every surface in Material Design is a sheet of this material at a specific elevation. Higher elevation = bigger shadow = more visual importance.

Key innovations:

  • Elevation & shadows — A systematic shadow model (0–24dp) that conveys hierarchy
  • Bold color — Primary/secondary color system with automatic contrast checking
  • Meaningful motion — Transitions that explain spatial relationships
  • Responsive layout grid — 8dp grid system for consistent spacing
  • Ripple feedback — Touch feedback that radiates from the point of contact

Material 3 (You) introduced dynamic color theming from wallpapers, updated component shapes, and a more expressive design language while maintaining the core elevation and motion principles.

When to use: Material Design is ideal for Android apps (it's the native design language), cross-platform apps needing a consistent system, and any project that benefits from a comprehensive, well-documented design system with extensive component libraries.
