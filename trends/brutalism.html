BRUTALISM

> raw HTML. exposed grids. no apologies.

Brutalism is design that refuses to seduce you. It throws out the rounded corners, the soft shadows, the polite whitespace, and the friendly gradients — and gives you the raw skeleton of the web instead: system fonts, default blue links, hard borders, and colors that clash on purpose. It is anti-design as a statement.

Exposed Grid

Brutalist layouts flaunt their structure. Borders are thick and black; the grid is not hidden behind padding and soft fills — it is the whole aesthetic.

Clashing Colors

High-contrast, deliberately uncomfortable color pairings — yellow on magenta, green on blue — reject the harmonized palettes of corporate design. The hard offset shadow (no blur) is a signature move.

/* The signature hard-offset shadow — zero blur */ .brutal-btn { border: 4px solid #000; box-shadow: 8px 8px 0 #000; /* solid block, no softness */ font-family: 'Courier New', monospace; text-transform: uppercase; } .brutal-btn:active { transform: translate(8px, 8px); /* button "presses" into the page */ box-shadow: 0 0 0 #000; }

Motion Without Polish

Brutalism revives unfashionable web relics — the scrolling ticker, blinking text, visible cursors — as ironic, knowing references to the early web.

System Fonts On Purpose

Brutalist sites embrace the browser's default fonts — Times New Roman, Courier, Arial — rather than loading a curated typeface. The "unstyled" look is the style.

When To Use / Avoid

USE IT FOR

  • Portfolios for designers/developers who want to stand out
  • Art, music, fashion, and counterculture brands
  • Landing pages that want to feel raw, urgent, anti-corporate
  • Projects making a deliberate statement about the web itself

AVOID FOR

  • E-commerce, banking, healthcare, government services
  • Any audience that values trust and predictability
  • High-volume conversion funnels (friction kills conversions)
  • Users with accessibility needs unless done very carefully

History & Theory

The name borrows from Brutalist architecture — the raw, exposed-concrete buildings of the mid-20th century, from the French béton brut ("raw concrete"). Architects like Le Corbusier celebrated honesty of materials: showing the structure rather than cladding it. Web brutalism applies the same ethic to interfaces — show the HTML, don't dress it up.

Web brutalism emerged around 2014–2016 as a reaction against the homogenized, template-driven sameness of corporate web design — the era when every site looked like the same Bootstrap landing page. Designer Pascal Deville popularized the movement with the curated gallery brutalistwebsites.com, which collected and celebrated raw, defiant sites.

Notable real-world examples:

  • brutalistwebsites.com — Pascal Deville's defining gallery of the movement.
  • Bloomberg Businessweek — its editorial features have repeatedly used clashing, "ugly," maximalist brutalist layouts for impact.
  • Craigslist & the original Hacker News — accidental brutalism: function-first, unstyled, and beloved for it.
  • Gumroad and Balenciaga's web experiments — brands adopting raw, high-contrast aesthetics deliberately.
  • Yale School of Art website — a famously chaotic, wiki-edited brutalist site.

Defining characteristics:

  • System / default fonts (Times, Courier, Arial) used unironically as the type system
  • Default blue/purple hyperlinks, visible underlines
  • Thick black borders and exposed grid structure
  • Hard, blur-free offset shadows
  • Clashing, high-saturation colors with no harmonized palette
  • Raw HTML elements left near their browser defaults
  • A knowing, sometimes confrontational tone — "anti-design"

The point: brutalism is not laziness — the best brutalist sites are meticulously crafted to look raw. It is a critique of frictionless, sanitized corporate UX and a reassertion of personality, honesty, and the weird, hand-built spirit of the early web.

Accessibility Notes

Brutalism and accessibility can conflict — but they don't have to. Raw doesn't mean inaccessible.

  • Color contrast is the biggest risk. Yellow-on-magenta and cyan-on-yellow often fail WCAG contrast ratios. Test every clashing pair — keep body text on combinations that still pass AA (4.5:1).
  • Keep semantic HTML. Brutalism actually favors plain HTML, which is good for screen readers — as long as you use real headings, buttons, and labels rather than styled divs.
  • Focus states must remain visible. Don't strip outlines just to look raw.
  • Motion (tickers, blinking) should respect prefers-reduced-motion and never be the only way to access content.
  • Default links are an accessibility win — underlined, color-distinct links are easy to identify.
