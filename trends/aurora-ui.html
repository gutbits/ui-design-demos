Anatomy of an Aurora

/* 1. A stage that holds the light, sitting behind your content */ .aurora { position: absolute; inset: -20%; /* overscan so blur has no hard edge */ filter: blur(80px); /* the heavy blur IS the effect */ } /* 2. A few oversized radial-gradient blobs */ .blob { position: absolute; width: 50vw; height: 50vw; border-radius: 50%; background: radial-gradient(circle, #5b7cfa, transparent 60%); mix-blend-mode: screen; /* colors add like real light */ animation: drift 18s ease-in-out infinite alternate; } /* 3. Slow, looping translate/scale keyframes give the living glow */ @keyframes drift { from { transform: translate(0,0) scale(1); } to { transform: translate(12vw, 8vh) scale(1.25); } }

Three ingredients, that's it

Big. Blobs are 40–50vw — far larger than they look once blurred. Blurred. A 60–100px blur dissolves them into soft ambient color. Additive. mix-blend-mode: screen makes overlapping colors brighten and blend like actual aurora light rather than muddy overlapping paint.

Accessibility & Performance

Keep text off the aurora — keep it on the glass

Because the background drifts and shifts hue, text contrast over a raw aurora is unstable and will fail WCAG 1.4.3 in places. The fix is the pattern Stripe and Linear actually use: put the aurora behind a solid or frosted-glass surface and place text on that surface, where contrast is controlled.

Respect motion preferences — gate the drift animation behind @media (prefers-reduced-motion: reduce) so users who get motion sick see a static gradient. And watch performance: large blur() filters and backdrop-filter are GPU-heavy, so keep blob counts low (3–5), animate only transform (not box positions), and add will-change: transform.

/* Honor reduced-motion — static aurora for sensitive users */ @media (prefers-reduced-motion: reduce) { .blob { animation: none; } } /* Text lives on a controlled surface, never on raw aurora */ .glass-card { background: rgba(255,255,255,0.06); backdrop-filter: blur(16px); color: #fff; /* contrast checked against the glass, not the glow */ }

History & Theory

Aurora UI (also called ambient gradients, gradient mesh, or simply "glow" backgrounds) describes the use of large, soft, blurred gradient blobs as an atmospheric backdrop — color that feels like light leaking in rather than a flat fill. The name evokes the aurora borealis: diffuse bands of shifting color.

It became the defining look of the early-2020s developer-tool and SaaS aesthetic. Stripe's animated gradient hero, Linear's dark ambient glows, and the gradient-heavy marketing of Vercel and many YC-era startups all share this DNA. The look pairs naturally with dark mode, glassmorphism, and bold gradient typography.

Defining characteristics:

  • Ambient color, not objects — the gradient is mood/atmosphere, sitting behind real content
  • Heavy blur — there are no hard edges; the blur dissolves blobs into pure color fields
  • Multi-hue blends — usually 3–5 colors (indigo, violet, fuchsia, teal, rose) melting together
  • Subtle slow motion — gentle drift gives a sense of life without demanding attention
  • Dark canvas — most auroras glow against a near-black background for maximum luminance contrast

Technically it can be built several ways: animated CSS radial gradients (shown here), a static SVG/PNG gradient-mesh export from a tool like a mesh-gradient generator, or WebGL/Canvas for richer, noise-driven motion. CSS-only is the lightest and most common for hero sections.

When to use: Landing pages, hero sections, dashboards, dev tools and any product that wants a modern, premium, atmospheric feel — especially in dark mode. When to avoid: content-dense reading interfaces, or anywhere the moving color competes with the content. The golden rule: aurora is a backdrop. Keep your text and controls on a controlled surface in front of it, and the effect stays both beautiful and usable.
